# Short-reply help

Levels: short, tighter, tightest. `stop` returns to normal sentences.

The user prompt is never rewritten. Code, commands, paths, and errors stay exact.

Related: one-line commit (`references/commit.md`), one finding per line (`references/review.md`).

This skill is not on after a normal install. Turn it on with `so install --voice`. It stays off until a paired run shows fewer provider-reported tokens in total.
