# Graph

The native code graph: Tree-sitter AST extraction → SQLite store →
`so graph *` queries. Builds are local and deterministic — no LLM, no network.
On Superopen's own source the full build indexes 7,371 nodes / 37,413 edges in
about five seconds.

## Lifecycle

```bash
so init            # create .so/ + first build (runs inside a repo)
so graph build     # full rebuild
so graph refresh   # incremental; skips when unchanged, or when .so/ is missing (--force for full)
so graph status    # build state of the current project
so graph projects  # every indexed project on this machine
```

Session hooks refresh the graph in the background on SessionStart /
SessionEnd (detached, fail-open) — only when the workspace already has `.so/`.

## Asking questions

| Command | Use for |
|---------|---------|
| `so graph query "<question>"` | Plain-language question → ranked subgraph. Default answer surface. |
| `so graph search <pattern>` | Find symbols by name (BM25 over FTS). |
| `so graph snippet <qn>` | Read the source of a known symbol (files clip at ~500 lines). |
| `so graph trace <symbol>` | Callers (`--direction incoming`), callees (`outgoing`), or both. |
| `so graph impact <symbol\|change>` | Blast radius with risk classification. |
| `so graph architecture` | Languages, packages, routes, hotspots, clusters. |
| `so graph schema` | Node labels, relationship types, property patterns. Run this first when scripting. |
| `so graph cypher "<query>"` | Read-only Cypher subset. |
| `so graph code-search` | Text search over indexed files only. |
| `so graph coverage` | What was indexed, what was skipped and why. |
| `so graph diagnostics` | Database integrity checks. |
| `so graph artifact` | Export/import/verify a content-addressed graph snapshot for teammates. |

## Output contract

Success output is compact text, not JSON:

```text
NODE steerTextFor [qn=internal.agent.hook.steerTextFor src=internal/agent/hook/steer_context.go loc=L104-110]
EDGE internal.agent.hook.steerTextFor -CALLS-> internal.agent.steer.HookReminder
help[]:
  so graph snippet internal.agent.hook.steerTextFor
```

- Answers stay under a token **budget** and a hard row cap (16 NODE / 16 EDGE
  rows); when results exceed either the header says
  `TRUNCATED: showing N of M listed nodes (R reachable)` and suggests `snippet` or a narrower
  question — it never silently drops the answer.
- `qn=` qualified names feed `snippet` / `trace`.
- `--json` / `--full` are script escape hatches; agent piping relies on the
  default shape.

## Data model

Labels include `Project`, `Package`, `Folder`, `File`, `Module`, `Class`,
`Function`, `Method`, `Interface`, `Enum`, `Type`, `Route`. Relationships
include `CALLS`, `USAGE`, `IMPORTS`, `DEFINES`, `IMPLEMENTS`, `HANDLES`,
`CONFIGURES`, `TESTS`. The live truth is `so graph schema`.

Identity rules: path-shaped names resolve File → Module; symbol-shaped names
resolve to a single callable or report `ambiguous` rather than guessing.
